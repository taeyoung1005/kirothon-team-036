# SkillPick 상세 UI 명세

- 원천 설계: `2026-11-14-skillpick-design.md`
- 시안 이미지: `docs/ui/mockups/*.png` (jdmnk-codex-imagegen 생성, 분위기·배치 참고용. 문구·수치·상태는 이 문서가 정본)
- 구현: Kiro. 이 문서가 화면의 원천이다

## 0. 공통

**창**: 기본 1440×900, 최소 1200×760. macOS 기본 제목 표시줄을 숨기고(신호등 버튼만) 상단 52px을 앱 툴바로 쓴다.

**톤**: 개발자 도구. 앱 껍데기는 짙은 중립 회색이고, 사용자가 비교할 시안(밝고 다채로운 웹페이지)이 가장 눈에 띄게 한다. Figma 캔버스처럼 시안이 주인공, 앱은 액자다.

**색 토큰** (한 곳에서만 정의)
| 토큰 | 값 | 쓰임 |
|---|---|---|
| `bg` | `#0E0F11` | 창 배경 |
| `surface` | `#16181B` | 패널·카드 |
| `surface-2` | `#1E2125` | 입력칸, 눌림 |
| `line` | `#2A2E33` | 1px 구분선 |
| `text` | `#ECEDEE` | 본문 |
| `text-dim` | `#9BA1A6` | 보조 |
| `accent` | `#7C8CFF` | 주 버튼, 선택 테두리 |
| `ok` | `#3DD68C` | 통과 |
| `warn` | `#F5A524` | 경고 (지어낸 숫자 의심, 일부 누락) |
| `bad` | `#F26D6D` | 실패 |

**글꼴**: Pretendard(본문·UI), JetBrains Mono(URL·명령·로그·시간). 크기 12/13/14/16/20/28. `word-break: keep-all`.

**간격**: 4의 배수. 패널 안 여백 20, 카드 사이 16. 모서리 반경 카드 12, 버튼·입력 8. 터치 대상 최소 32px 높이(데스크톱 앱).

**문구 규칙**: 한국어, 짧게. 문장 끝 마침표 쓰지 않음. em dash 쓰지 않음. 하지 않는 일을 한다고 쓰지 않음.

**레이아웃 뼈대**
```
┌──────────────────────────────────────────────────────────────┐
│ ● ● ●  SkillPick     [단계 표시: 입력 › 확인 › 생성 › 비교]   ⚙ │ 52px 툴바
├────────────┬─────────────────────────────────────────────────┤
│ + 새 비교   │                                                 │
│            │                 본문 (단계별 화면)                │
│ 최근 비교   │                                                 │
│ · aibuild… │                                                 │
│ · lumen…   │                                                 │
│ 220px      │                                                 │
└────────────┴─────────────────────────────────────────────────┘
```
- 왼쪽 사이드바: `+ 새 비교`, 최근 실행 목록(사이트 도메인, 스킬 수, 상대 시간). 실행 중이면 점 애니메이션.
- 툴바 가운데 단계 표시: 지난 단계는 눌러 돌아갈 수 있음(생성 중에는 잠김).
- 툴바 왼쪽 여백은 창 제어 버튼(신호등) 폭에 맞춰 정한다. 글자는 왼쪽에서 100px부터 시작한다(`tokens.css`의 `--traffic-x`는 `electron/main.js`의 `trafficLightPosition.x`와 같은 값).
- 비교 단계(화면 5, 6)에서는 사이드바 220px을 기본으로 접는다. 비교 화면 상단의 `☰ 최근 비교`로 다시 연다. 접힘은 비교와 크게 보기가 한 묶음으로 기억하고, 그 밖의 화면은 따로 기억한다(기본은 펼침). 접고 펴도 화면을 다시 그리지 않아서 시안 뷰가 다시 불러와지지 않는다.

## 화면 1. 준비 확인 (첫 실행, 또는 Kiro 상태가 나쁠 때만)

목적: BYOK 전제(내 Kiro CLI 로그인)를 앱이 직접 확인한다.

```
          SkillPick
          내 페이지에 디자인 스킬을 한 번에 돌려 보고 결과로 고르세요

          ┌ 준비 상태 ─────────────────────────────────┐
          │ ✓ kiro-cli 설치됨        3.1.0              │
          │ ✓ Kiro 로그인됨          tae…@…             │
          │ ✓ 동시 실행 설정         3개                 │
          └────────────────────────────────────────────┘
                         [ 시작하기 ]
```
- 항목 상태: 확인 중(스피너) / ✓ / ✗ + 해결 방법.
- 설치 안 됨: `✗ kiro-cli를 찾지 못했어요` + 설치 명령 한 줄(복사 버튼) + `다시 확인`.
- 로그인 안 됨: `✗ 로그인이 필요해요` + `kiro-cli login` 복사 + `다시 확인`.
- 모두 ✓면 `시작하기` 활성. 다음 실행부터는 이 화면을 건너뛰고 백그라운드로만 확인한다.

## 화면 2. 새 비교 (URL + 스킬 고르기)

```
┌ 어떤 페이지를 바꿔 볼까요 ───────────────────────────────────┐
│ [ https://                                                  ] │
│  불러왔어요 · 지켜야 할 것 14개                                │
└──────────────────────────────────────────────────────────────┘
┌ 어떤 스킬로 돌려 볼까요                  [+ SKILL.md 주소로 추가] ┐
│ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐           │
│ │☑ frontend-    │ │☑ web-design- │ │☐ ui-ux-pro-  │           │
│ │  design     ↗ │ │  guidelines ↗│ │  max        ↗│           │
│ │ Anthropic     │ │ Vercel       │ │ nextlevel…   │           │
│ │ 대담한 미감,   │ │ 접근성·관례  │ │ 스타일 50종  │           │
│ │ 뻔한 AI 느낌   │ │ 점검 중심    │ │ 지침만 적용   │           │
│ │ 피하기         │ │              │ │ [스타일 고르기 ▾]│        │
│ └──────────────┘ └──────────────┘ └──────────────┘           │
│  …                                                            │
├──────────────────────────────────────────────────────────────┤
│ 3개 선택 · 시안 3개 · 동시 3개                  [원본 확인 →]   │  맨 아래 고정 바
└──────────────────────────────────────────────────────────────┘
```
- URL 입력: 모노 글꼴. `[불러오기]` 버튼은 없다. Enter를 누르거나 입력칸을 벗어나면 바로 원본 수집을 시작한다.
- URL 아래 한 줄은 상태 하나만 보인다.
  | 상태 | 문구 |
  |---|---|
  | 안내 | `공개 페이지나 localhost 주소를 넣으세요` |
  | 수집 중 | `페이지를 불러오는 중이에요` (스피너) |
  | 성공 | `불러왔어요 · 지켜야 할 것 n개` |
  | 실패 | `이 페이지를 열지 못했어요 · Enter로 다시 시도` (빨간 글씨). 같은 주소로 Enter를 다시 누르면 새로 시도 |
  | 주소 오류 | `http 또는 https 주소만 넣을 수 있어요` (빨간 글씨) |
- 스킬 카드 격자: 창 폭에 맞춰 열 수가 늘어난다. 카드 최소 폭 260px, 창 1200폭에서 3열, 1440폭에서 4열. 카드는 체크박스, 이름(모노), 제작처, 한 줄 설명(두 줄 넘으면 말줄임), 꼬리표(`지침만 적용`, `직접 추가`). 카드 전체가 눌림 영역. 선택 시 `accent` 테두리.
- 꼬리표는 중립 색이고 마우스를 올리면 뜻이 보인다. `지침만 적용`: `셸 명령과 스크립트는 실행하지 않고 글로 된 디자인 지침만 따라요`. `직접 추가`: `주소로 직접 추가한 스킬이에요`.
- 카드 오른쪽 위 `↗`: 출처 GitHub 열기.
- 스타일이 있는 스킬은 카드 아래에 칩 `스타일 고르기 ▾`. 고른 뒤에는 `스타일 n개 고름 · 바꾸기`. 안 고른 칩에 마우스를 올리면 `안 고르면 스킬이 알아서 정해요`. 누르면 대화상자 `<스킬 이름> 스타일 고르기`가 열린다: `스타일 이름 찾기` 입력, 목록(체크), `n개 고름 · 고른 스타일마다 시안이 하나씩 만들어져요`, `닫기` `모두 해제` `고르기`. 목록을 못 읽으면 `스타일 목록을 읽지 못했어요`. 스타일을 고르면 그 스킬도 선택되고, 스킬 선택을 풀면 고른 스타일도 지워진다.
- `+ SKILL.md 주소로 추가`: 작은 대화상자. 주소 입력 → `가져오기` → 미리보기(이름·첫 3줄) → `추가`. 실패: `이 주소에서 SKILL.md를 읽지 못했어요`.
- 맨 아래 고정 바: 왼쪽에 `n개 선택 · 시안 n개 · 동시 n개`(스타일을 고르면 시안 수가 스킬 수보다 늘어난다), 오른쪽에 `원본 확인 →`. 예전 헤더의 `동시에 3개씩 만들어요`는 바의 `동시 3개`로 대체했다.
  - 시안이 12개를 넘으면 바에 `시안은 한 번에 12개까지예요`를 빨간 글씨로 보이고 버튼을 끈다.
  - 선택이 0개면 바에 `스킬을 하나 이상 골라 주세요`를 보이고 버튼을 끈다.
- `원본 확인 →`: 주소가 잘못이면 입력칸으로 돌아가 오류를 보인다. 아니면 화면 3으로 이동한다. 수집은 주소를 넣을 때 이미 시작돼 있고, 같은 주소를 이미 불러오는 중이면 그대로 이어서 쓴다.

## 화면 3. 원본 확인 (지켜야 할 것)

목적: 시안이 무엇을 반드시 지킬지 사용자가 보고 동의한다. 데모에서 "이 14개는 어떤 스킬도 못 바꾼다"를 보여 주는 화면.

```
┌ 원본 ───────────────────────┐ ┌ 지켜야 할 것  14/14개   [모두 해제] ┐
│ [데스크톱|모바일]            │ │ 모든 시안이 이 항목을 그대로 담아야 │
│ ┌─────────────────────────┐ │ │ 통과해요                            │
│ │                         │ │ │ ▾ 제목 (1)             [모두 해제]  │
│ │   (원본 1440 캡처,       │ │ │ ☑ AI 빌더를 위한 커뮤니티            │
│ │    세로 스크롤)          │ │ │ ▾ 소제목 (2)           [모두 해제]  │
│ │                         │ │ │ ☑ 이번 주 행사  ☑ 함께 만든 것들    │
│ │                         │ │ │ ▾ 버튼 (1)             [모두 해제]  │
│ │                         │ │ │ ☑ 지금 참가하기 → /join             │
│ └─────────────────────────┘ │ │ ▸ 내비 (3/7)           [모두 선택]  │
│ theaibuilders.dev · 2.1초    │ │                                    │
│ ─────────────────────────── │ │                                    │
│ 수집한 에셋 [이미지 12] [로고 2]│ │                                    │
└─────────────────────────────┘ └────────────────────────────────────┘
├──────────────────────────────────────────────────────────────────────┤
│ [← 스킬 다시 고르기]                              [시안 3개 만들기 →]   │  맨 아래 고정 바
└──────────────────────────────────────────────────────────────────────┘
```
- 수집 중: 왼쪽에 캡처 자리 스켈레톤 + `페이지를 열고 있어요`, 오른쪽 목록 스켈레톤. 상한 20초. 아래 바에는 `← 스킬 다시 고르기`만 있다.
- 수집 실패: 가운데 `이 페이지를 열지 못했어요` + 사유(시간 초과/차단/주소 오류) + `← 스킬 다시 고르기` `다시 시도`.
- 맨 아래 고정 바: `← 스킬 다시 고르기`, `시안 n개 만들기 →`. 켜진 항목이 0개면 만들기 버튼을 끈다. 시작에 실패하면 버튼 글자가 `시작하지 못했어요 · 다시 눌러 주세요`로 바뀐다.
- 헤더 `지켜야 할 것  24/24개`는 켜진 수/전체 수. 오른쪽 `모두 해제`는 전부 켜져 있을 때, 아니면 `모두 선택`.
- 목록: 종류별 묶음(제목·소제목·첫 단락·버튼·가격·내비). 체크 해제하면 그 항목은 검사에서 뺀다.
  - 종류 머리를 누르면 접고 펼친다(`▾` 펼침, `▸` 접힘). 항목이 7개 이상인 종류는 처음부터 접혀 있다.
  - 종류마다 `모두 해제`/`모두 선택`이 있다. 일부만 켜면 머리에 `내비 (3/7)`, 전부 켜면 `내비 (7)`.
  - 버튼·링크는 `글자 → 경로`(경로는 모노, 흐리게). 같은 사이트는 경로(`/join`), 다른 사이트는 주소(`https://example.com/docs`)로 보인다. 쿼리는 `?…`로 줄이고, 해시는 `#about`처럼 보인다. 값이 실린 해시(`#access_token=…` 같은 것)는 `#…`로 줄인다. 검사에는 원래 주소를 쓴다.
- 상한 25개. 줄였다면 목록 위 안내 `⚠ 항목이 많아 소제목과 내비 일부를 뺐어요`.
- 원본 패널 아래 `수집한 에셋` 한 줄: `이미지 n` `로고 n` `아이콘 n` `SVG n` `영상 n` 칩. 0인 종류는 숨기고, 전부 0이면 `없어요`. 마우스를 올리면 `시안에 쓸 수 있게 원본에서 모은 에셋이에요`. 에셋을 하나씩 고르는 기능은 없다.
- 원본 캡처 위에 마우스를 올리면 해당 항목을 목록에서 강조하는 연결은 하지 않는다(범위 밖).

## 화면 4. 생성 중

목적: 동시에 도는 것을 정직하게 보여 준다. 실제 상태만.

```
 theaibuilders.dev · 스킬 3개 · 동시 3개 실행 중 · 대기 0          04:12
┌ frontend-design ──────────────────────────────────────────────┐
│ ● 만드는 중   02:13                                            │
│ ▕█████████░░░░░░░▏  단계: 생성 → 검사 → 완료                     │
│ > fs_write out/index.html (18.2 KB)                            │
│ > 히어로 섹션 작성                                              │
├ web-design-guidelines ────────────────────────────────────────┤
│ ◐ 검사 중     03:40      지켜야 할 것 13/14 확인 중               │
├ ui-ux-pro-max ────────────────────────────────────────────────┤
│ ↻ 다시 고치는 중 (1/1)  05:02   빠진 항목: 가격 ₩0               │
└───────────────────────────────────────────────────────────────┘
                 [완료된 것부터 보기]          [전부 멈추기]
```
- 한 줄 = 시안 하나. 상태 배지: `대기`(회색) `만드는 중`(accent, 점 애니메이션) `검사 중` `다시 고치는 중 (1/1)`(warn) `완료`(ok) `실패`(bad) `시간 초과`(bad).
- 진행 막대는 실제 단계 3개(생성·검사·완료)만 표시한다. 가짜 퍼센트 없음.
- 로그 꼬리: Kiro 출력의 마지막 2줄(모노, 흐리게). 줄을 누르면 전체 로그 펼치기.
- 상단 요약 줄의 `동시 n개 실행 중 · 대기 m`은 실제 실행 중인 프로세스 수.
- `완료된 것부터 보기`: 하나라도 완료되면 활성. 화면 5로 가되 생성은 계속된다(미완료 카드는 상태로 표시).
- 전부 끝나면 자동으로 화면 5로 넘어가지 않고 버튼이 `비교하기 →`로 바뀐다.
- `전부 멈추기`: 확인 없이 즉시 모든 자식 프로세스 종료. 상태는 `멈춤`.

## 화면 5. 비교 격자 (핵심 화면)

```
 [☰ 최근 비교] [theaibuilders.dev 시안 3개] [데스크톱|모바일] [☐ 통과한 것만] [↕ 같이 스크롤]  …  [정렬: 완료 순 ▾]
```

- 카드 열 수는 창 폭과 보기 폭에 상관없이 항상 2열. 첫 줄은 `원본 | 시안 1`.
- 카드 높이는 창 높이의 약 60%(최소 420px)로 고정한다. 카드 안에서 세로 스크롤하고 머리와 정보줄은 고정이다.
- 카드는 시안을 실제로 렌더한 격리 뷰를 줄여 보여 준다. 데스크톱은 1440폭을 카드 폭에 맞춰 줄이고, 모바일은 390폭 프레임을 카드 가운데에 둔다(카드가 390보다 좁으면 줄인다).
- 원본 카드는 항상 맨 앞, 테두리 점선. 실제 렌더 대신 수집할 때 찍은 전체 캡처를 쓴다.
- 카드 머리는 두 줄: 스킬 id(모노), 스타일 이름. 스타일이 없는 시안은 둘째 줄이 비어 있다. 원본 카드는 `원본`, 도메인. 머리를 누르면 화면 6(오른쪽 `크게 보기 ↗`).
- 카드 아래 정보줄: 검사 결과 배지(`✓ 14/14` 또는 `⚠ 13/14`), 경고 꼬리표(`가격 누락`, `지어낸 숫자 1`, `콘솔 오류 2`), 걸린 시간, 오른쪽 `이걸로 고르기`. 원본 카드 정보줄은 `수집할 때 찍은 화면`.
  - 경고 꼬리표: 빠진 종류(`제목 누락` `소제목 누락` `첫 단락 누락` `버튼 누락` `가격 누락` `내비 누락`), `지어낸 숫자 n`, `외부 스크립트 n`, `외부 전송 폼 n`, `파일이 너무 커요`, `콘솔 오류 n`.
  - `이걸로 고르기`는 완료된 시안에만 있다. 크게 보기를 거치지 않고 화면 7 패널을 바로 연다. Esc나 `✕`로 닫는다.
  - 실패·시간 초과·멈춤 카드는 렌더 대신 사유와 `로그 보기`(누르면 `로그 닫기`)를 보인다. 본문 글자는 멈춘 것이면 `멈췄어요`, 아니면 `이 시안은 만들어지지 않았어요`.
- 미완료 카드는 상태 배지와 경과 시간만 보인다. 끝나면 새로 고치지 않아도 그 자리에서 미리보기로 바뀐다.
- 상단 바: `[☰ 최근 비교] [요약 칩] [데스크톱|모바일] [통과한 것만] [↕ 같이 스크롤] … [정렬]`.
  - `☰ 최근 비교`: 사이드바를 펴고 접는다(기본은 접힘).
  - 요약 칩: 도메인과 `시안 n개`. 마우스를 올리면 전체 주소.
  - 데스크톱/모바일 전환은 모든 카드에 한꺼번에 적용한다. 원본 카드의 캡처도 같이 바뀐다.
  - `통과한 것만`: 완료이고 검사를 통과한 시안만 남긴다. 켜면 `통과한 시안 n개 · 전체 m개`가 보인다.
  - `↕ 같이 스크롤`(구현됨): 켜면 한 카드를 스크롤할 때 나머지 카드가 같은 비율로 따라간다. 원본 카드도 포함한다. 숨겨진 카드는 따라가지 않는다.
  - 정렬: `정렬: 완료 순`(끝난 시각 순, 미완료는 뒤) 또는 `정렬: 이름 순`.
  - 만드는 중인 시안이 있으면 오른쪽에 `n개 만드는 중`과 `생성 상태 보기`(화면 4로)가 보인다.
- 정렬과 필터는 카드를 옮기지 않고 순서와 표시만 바꾼다. 옮기면 시안 뷰가 다시 불러와지기 때문이다.

## 화면 7. 고른 뒤 (가져가기)

열리는 곳은 둘이다. 화면 5 카드의 `이걸로 고르기`(크게 보기를 거치지 않고 바로)와 화면 6의 `이 스킬로 고르기`. 같은 패널을 쓴다.

```
┌ frontend-design 을 골랐어요 ─────────────────────────┐
│ 1  스킬 설치                                          │
│    출처  github.com/anthropics/skills/…  [복사]       │
│    설치 안내 (쓰는 도구에 맞게)                         │
│    Kiro   .kiro/steering 에 넣기   [내 프로젝트에 내보내기] │
│    기타   [설치 명령 복사]                              │
│ 2  시안 코드                                           │
│    index.html · 18.2 KB  [HTML 저장]  [폴더 열기]      │
│ 3  이 비교 기록                                        │
│    최근 비교에 저장돼요                                 │
└──────────────────────────────────────────────────────┘
```
- `내 프로젝트에 내보내기`: 폴더 선택 대화상자 → 그 폴더의 `.kiro/steering/design-<스킬ID>.md`로 저장. 이미 있으면 `덮어쓸까요?` 확인. 완료 시 `저장했어요 · 경로` 토스트.
- `HTML 저장`: 저장 대화상자, 기본 이름 `<도메인>-<스킬ID>.html`.
- 설치 명령은 스킬 출처가 지원하는 경우에만 보인다. 확인되지 않은 명령은 쓰지 않는다.

## 설정 (⚙)

- 동시 실행 수(1~6, 기본 3), 시안당 시간 제한(기본 8분), 재시도 켜기/끄기, 엔진 표시(`Kiro CLI` 고정. 예비 엔진으로 바뀌면 `Anthropic API` + 키 입력칸).
- 실행 기록 폴더 열기, 기록 전부 지우기(확인 필요).
