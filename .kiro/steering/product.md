# 제품 규칙: SkillPick

- 대상: 자기 서비스를 직접 만드는 개발자·1인 창업자
- 불편: 홈페이지 디자인을 매번 고민하고, 디자인 스킬이 너무 많아 고르지 못함
- 약속: URL 하나에 여러 디자인 스킬을 동시에 돌려 결과를 나란히 보여 주고, 결과를 보고 고르게 한다
- 모든 시안은 원본의 카피·가격·버튼·링크(지켜야 할 것)를 그대로 담아야 비교 화면에서 통과로 표시된다

## 반목표 (돌아가도 실패)
- 지켜야 할 것을 빠뜨리거나 지어낸 시안이 통과로 보이는 것
- 원본 페이지 글자 속 지시문 때문에 사용자 컴퓨터에서 명령이 실행되는 것
- 실제로는 하나씩 도는데 동시에 도는 것처럼 보이는 것
- 미리 만든 결과를 재생하면서 실시간인 척하는 것

## 문구
- 한국어, 짧게. 문장 끝 마침표와 em dash를 쓰지 않는다
- 화면 문구는 `docs/superpowers/specs/2026-11-14-skillpick-ui.md`를 그대로 쓴다
- `docs/ui/mockups/*.png`는 분위기 참고다. 이미지 속 글자와 스킬 이름을 옮기지 않는다
